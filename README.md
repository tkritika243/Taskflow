TaskFlow – Task Management Application

About the Project

TaskFlow is a Full Stack Task Management Web Application that helps users manage their daily tasks efficiently.

Features

- User Registration
- Secure Login
- Add New Tasks
- View Tasks
- Mark Tasks as Completed
- Delete Tasks
- JWT Authentication

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT

Project Structure

- backend – Server-side code and APIs
- frontend – User interface

How to Run

1. Open the backend folder.
2. Run "npm install".
3. Configure your MongoDB connection and JWT secret in ".env".
4. Run "node server.js".
5. Open the frontend using Live Server.
